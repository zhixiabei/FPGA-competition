# 安路 PH1P35 边缘检测 + OSD 合并工程

## 2026-10-10 右侧接缝与目标框偏移修复

光照适应版曾将 AWB 像素延迟从原来的 54 拍缩短到 2 拍，却保留早到的帧首标志。
真实 `video_in` 和原 128 位异步 FIFO 的仿真复现：帧首与第一数据只差 3 个摄像头
时钟时，FIFO 展宽复位及同步释放会丢掉前 9 个字，即 144 字节、48 个 RGB 像素。
DDR 存入的图像因此左移 48 像素，行尾混入下一行开头，框坐标却仍对应完整源图像，
表现为右侧接缝和框向右偏。四种 DDR 时钟相位都复现相同结果。

修复只在 `user_source/hdl_source/awb.v` 的视频输出增加 52 拍固定延迟，
总延迟恢复 54 拍，早到帧首标志保持。缓存为 64×96 位分布式 RAM，
有效信号同步延迟；不恢复旧 2048 项 RAM，也不使用 4992 位像素移位寄存器。
AE 统计、白平衡增益计算、红色检测规则及框补偿没有因这处接缝修改。
完整视频通路沿用早到 SOF 的接口，帧间消隐需让上一帧的延迟像素排空。

此故障能解释接缝和坐标偏移，但丢失量恰为完整 RGB 像素，不会造成全屏
RGB 通道轮换；不能据此把固定的淡粉色或实物曝光响应也判为已解决。
真实 FIFO 的回归入口与验证范围见 [sim/README.md](sim/README.md)。

## 光照适应：自动曝光、帧稳定白平衡与红色判定（2026-10-10）

当前版本针对强光粉红边缘误识别、暗红物体漏检，增加完整帧反馈曝光，
替换白平衡统计和更新方式，并将红色判断改为通道比例及红色色相范围。
原 SC520CS 初始化/增益寄存器表、Scharr、K1 切换、DDR、OSD、PLL、
引脚和下载设置保持现有配置。

- **自动曝光**：AWB 前每完整 720p 帧抽取 7,200 个像素，统计亮度
  `(R+2G+B)/4` 和高光数量。`Y>=232` 为高光，亮度累加只包含非高光样本，
  以非高光区域平均亮度 96..128 为目标；饱和单个颜色通道不会自动被排除。
  至少 25% 采样属于非高光时允许因偏暗增亮；非高光低于 12.5% 时减亮，
  非高光达到 12.5% 但未到 25% 且偏暗时保持，避免比例门槛附近反复增减。
  已撤销“高光超过 1/32 就减亮”的旧规则，它会让亮屏或灯泡压暗周围物体。
  增亮先延长曝光再加增益，减亮先降增益再缩短曝光。
  初始化后先写入曝光 1000、增益 16；控制范围分别为 4..1991、16..144。
  每次写入等待实际 I²C busy→done，并忽略之后 3 个完整帧以避免连续追赶旧图像。
  无完整帧则保持参数。曝光值为原表控制码，不是毫秒；增益仍由原表映射。
- **白平衡**：仅从完整帧的未饱和、近中性色样本计算红/蓝增益，
  在后续帧首提交并以差值的 1/8 平滑，同一帧内增益固定。
  全红、全黑、全白饱和或样本不足时保持旧增益。
  共享一份顺序除法器取代两份旧流水除法器，旧 AWB 延迟 RAM 不再实例化。
  统计分级流水，四像素/拍的视频输出保持 54 拍总延迟，保留早到的帧首标志；
  其中颜色运算两拍、64×96 分布式 RAM 延迟 52 拍。
- **红色判断**：保留 `R>=24`、`R-G>=6`、`R-B>=6` 的暗噪声下限，
  再要求 `2R>=3G`、`2R>=3B`、`3G<=R+2B`、`3B<=R+2G`。
  将红色色相限定在 ±20°，同时要求 G、B 均不超过 R 的 2/3，
  因而 HSV 饱和度至少 1/3；比只限制 HSV 色相/饱和度更严格。
  使用移位/加法/比较实现，无 HSV 除法器或额外 DSP。测试中的暗红 `(35,10,8)` 可命中，
  强粉红 `(255,170,190)` 被排除。
  原 3×3 多数滤波、最小面积/尺寸、目标框及 DDR 帧对应方式保留。

AE 统计通过 64 位请求/确认邮箱进入约 23.81 MHz 控制域；
重复相同统计的帧仍产生脉冲，忙碌时 pending 帧可合并为最新值。
两份 SDC 只豁免请求/确认进入第一级同步寄存器的路径，稳定载荷受 20 ns
最大延迟约束；第二级继续正常检查。原诊断快照仍受 13 ns 约束。
第三格摄像头状态改为“首次曝光/增益写入已实际完成”，后续正常自动更新
不会因写忙而变红，不再要求固定 1991/144。

2. 检查目标器件和顶层名称，然后运行 Synthesis。
3. 再运行布局布线，查看资源和时序报告；通过后生成下载文件。
4. 没有开发板也可以编译；下载和摄像头、HDMI 实物验证需要 HX1P35A。

不要把整个源码文件夹中的所有 .v 再加入工程：其中有历史版本和同名模块。
特别是 data_96bit_to_128bit 模块已经由 isp/data96_128/data96_128.v 提供，不能再添加根目录的同名模块文件。
有效引脚约束为 user_source/constraints_source/pin.adc；有效顶层时序约束为 td_project/anlogic_edge_osd.sdc。
