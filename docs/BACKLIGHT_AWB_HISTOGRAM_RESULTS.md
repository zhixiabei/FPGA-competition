## 当前实现

### RAW 统计与曝光

`isp/ae_frame_stats_raw10_4x.v` 在 LSC 前复用原采样坐标：
720p 每帧 28,800 个 Bayer 分量，黑电平参数保持 0。
精确 RAW8 截顶均值的上限仍为 192，新增黑电平处理后 RAW10 的 32 桶直方图；
桶宽 32 个 RAW10 码，输出 P5/P50/P95/P99 的五位桶编号。
这不是显示亮度 Y 的直方图，没有进行各 RGB 通道均衡化。

近顶阈值改为 RAW8≥248，当前相当于原始 RAW10≥992；
到顶计数独立判断扣黑前原始 RAW==1023。它不能证明传感器在较低码值时没有内部剪切。
生产控制只接入 P95；其他百分位和分阶段计数供可选诊断使用。

统计采用单组分布式 RAM 和一个每拍更新一桶的共享端口：
四个采样分量排队，在四拍内处理，重复命中同桶不会漏计。
生产最后六行不采样，足够完成末尾四拍排空和 32 拍 CDF 扫描/清零；
因此不需要方案预估的双组桶，也不依赖行/帧消隐，不反压视频。
8/16/32 桶均有回归；生产仍保留 32 桶。不满足采样间隔或尾部调度的参数直接拒绝。

只有完整帧、行标志正确、计数达到目标且直方图已完成时发布。
截断、错误行或过早 SOF 不发布；若中断时桶未清好，会丢弃首个恢复帧的统计后再恢复。
这些丢弃不影响像素继续流动。

AE 采用一个有界全局评分：

```text
bias = P95 <= 23 ? 0 : 2 * (P95 - 23)       // 0..16
frame_score_sum = exact_capped_sum + sample_count * bias
```

六帧累计每帧自己的评分，不把最后一帧的 P95 套到整个窗口。
评分仍用 96～120 死区决定方向；原曝光/增益顺序、E4～1991/G16～176、
最小曝光步长 1、I²C busy/done 握手、写后三帧等待均保留。
高光不再产生独立的反向命令或锁存；即使 P95 到顶，全局截顶均值小于 80 时仍会增亮。

这是一种资源受限的全局曝光折中，**没有实现已标定的主体 ROI、主体最低可辨亮度或明确剪切预算**。
它不能保证所有窗景同时保住室内与窗外，也不代表这些阈值已有实景标定。
下一步应以曝光包围、分颜色余量和暗部噪声决定是否加入 ROI 或调整高光权重。

AE 统计包扩为 69 位：`{P95[4:0],sum[31:0],count[15:0],near[15:0]}`，
原低 64 位布局保留。握手邮箱整包传输，允许目的时钟停顿时排队并保留最新待传摘要。

### 白平衡

生产 `awb.v` 开启 `CONFIDENCE_ENABLE=1`，保留红蓝像素乘法器、绿色直通、
一个顺序除法器、帧首提交、1/8 平滑及原 54 拍像素延迟。
新增完整行/帧检查、上下半幅合格样本覆盖、连续两帧候选一致性和增益死区。
低可信保持上次增益，上电仍使用 Q8=256 的单位增益。
连续四次可信度失败后允许重新捕获，避免跟踪窗口永久锁住旧光源。

初始捕获增益范围为 Q8 170～512，候选差允许 24，跟踪差允许 64，
增益死区为 2；同向绿/品红偏移还有保守保护。
这些是可配置的临时边界，不是该相机在日光/暖白/冷白下的实测光源轨迹。
RGB 本身不能区分彩色墙与真正偏绿/偏品红光源下的中性物；
这类模糊场景保持旧增益，需用灰板数据重新限定捕获范围。

AE 初始化、写入及等待期间，经两级同步的 hold 会取消尚未提交或正在计算的 AWB 候选。
任何被 hold 触及的统计帧不用于更新，含帧首、末像素和统计流水尾部的短脉冲。
恢复后需重新满足候选一致性条件。像素通路及帧首提前标记保持原时序。

### 等价资源回收

AWB 分子由固定 40 位改为 `SUM_BITS+8`，生产为 30 位；每色仍保持 40 拍除法，
共享减法、符号差值及平滑运算，保留可见提交时间。
通用宽图参数仍支持原最大宽度，单独做逐拍等价回归。

生产 AE 显式设 `FIXED_SAMPLE_COUNT=28800`，保留输入计数相等检查，
将计数乘积和窗口分母常量化。`CHECK_BRIGHT_COUNT=0` 去掉源端完整摘要已保证的
`near<=count` 冗余检查，使无诊断时无用途的近顶计数跨域硬件可被裁剪。
通用默认仍检查非法 near；等价结论限定于源端合法的生产摘要。

生产 RAW 统计设 `HOLD_OUTPUTS=0`，仅在 `O_stats_valid` 周期提供完成帧的注册累加器值，
省去重复结果快照；不能在 valid 外读取它，也不能改接 `sum_next` 等组合下一值。
同步消费者即使与下一 SOF 同拍抓取，也读到旧帧完整结果，CDC 自身再保持提交包。
通用默认 1 仍保留旧接口的持续保持行为；两种配置已并行比较。

### Gamma 与 LSC

原 Gamma 全表及 LSC 标定系数保留，显示仍为十三模式，检测和 OSD 使用原通路。
仅给 LSC/AWB 增加默认关闭的内部运算溢出观察口，区分自然顶码与校正后被限幅。
没有根据拍屏照片改写空间标定、添加局部 HDR 或声称恢复已剪掉的纹理。

## 可选板上诊断入口

常用版本保持顶层 `IQ_DIAGNOSTIC_ENABLE=0`，诊断模块和保留寄存器均不生成。
需要取数时在 `design_top_wrapper`，或 capture 工程的 `sc520_capture_top`，将参数设为 1 后编译。
两份 `.al` 已登记 `isp/iq_diagnostic_stats.v`，没有增加物理引脚。

ChipWatcher 以 `S_csi_rx_clk` 为采样时钟，抓取顶层 generate `iq_diagnostics` 中的
`valid` 和 `data[127:0]`；capture 工程层次前加 `u_video/`。
寄存器使用 TD 支持的 `keep/preserve`，data 在有效包时更新，其他周期保持。
配置 valid 为 Data+Trigger、data 为 Data，触发 `valid==1`，按每个 valid 周期解码，
因为包可能连续多拍，不能只捕获 valid 上升沿。
可从 128 深度、Input/OutputPipe=0 开始检查单次数据突发；
这不能保证抓到整帧所有阶段的包，完整对照时需加深或分阶段抓取并匹配源帧号。
插入 ChipWatcher 核会额外消耗资源/RAM；它是临时诊断构建，不包含在常用版本资源数字里。
独立门级检查确认命名数据总线与 valid 均保留；真实包中的恒零位可折叠为常量端点，
不能据此要求所有128位都各占一个物理FF。完整保留证据与手册页码见
`build/backlight_awb/probe_preservation/README.md`。

所有包共用头部 `[127:124]kind`、`[123:122]channel`、`[121:112]source_frame_id`。
RAW/LSC 通道是 R=0、Gr=1、Gb=2、B=3；RGB 为 R=0、G=1、B=3。

| kind | 数据字段 |
|---|---|
| 0 RAW / 1 LSC | count[111:96]、sum[95:72]、near[71:56]、clip[55:40]、扣黑后 near[39:24]，低24位为0 |
| 2 preAWB / 3 postAWB | count[111:96]、sum[95:72]、near[71:56]、clip[55:40]，低40位保留为0 |
| 4 RAW 百分位 | P5[111:107]、P50[106:102]、P95[101:97]、P99[96:92]、count[91:76]、near[75:60]、RAWclip[59:44] |
| 5 AWB 状态 | 帧应用 R 增益[111:101]、B 增益[100:90]、统计完成时 candidate 状态[89]、合格样本数[88:73] |

RAW/LSC 的 near 阈值为 992，RGB 的 near 阈值为 248。
RAW clip 是原码等于 1023，preAWB clip 是输入分量等于 255；
LSC/postAWB clip 是内部算术溢出标志，不是简单数输出顶码。
RAW/LSC 每色 7,200 个样本；RGB 每通道最多 14,400 个轮换抽样样本。
RAW near 依据原始码，包内另给扣黑后的 near；生产 BLC=0 时二者相同。
kind5 的 candidate 状态不是“本帧稍后计算出的商已获准提交”的证明。

这是独立源帧统计，不绑定当前 DDR/HDMI 槽；没有实时直方图 OSD。
输出无反压，新快照可替换尚未排空的旧快照；解码应按每包自己的 kind/channel/源帧号归组。
具体原语保留属性依据 TD 本机 SWUG106 §4.2.4、§4.2.14，
ChipWatcher 配置与缓存依据 SWUG111 第 2 章。

后续用固定增益的原曝光/约 1/2/约 1/4 曝光对照区分传感器、LSC、AWB 和显示造成的发白，
再在单光源中性板上确定 AWB 捕获范围、主体最低亮度及允许高光损失。
没有这些数据，不能承诺实际窗外纹理或混合光源颜色已经改善。
