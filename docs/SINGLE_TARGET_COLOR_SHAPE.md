# 单目标形状识别

SW2 OFF 时，K2 在红、绿、蓝和运动检测间切换。当前单目标形状逻辑位于 `user_source/hdl_source/isp/red_target_detect_96.v` 的 `red_single_shape_engine`，描述器识别正方形、圆形和三角形，不满足条件时输出 UNKNOWN。

## 轮廓处理

当前逻辑在上一条有效行支持缺口两侧时，有限度补齐内部缺口，再统一计算轮廓面积、矩和外周长：

- 单个缺口最多 16 像素。
- 每行补点不超过 `min(16, max(2, 行跨度/4))`。
- 总补点不超过原始颜色面积的 1/32。
- 连续修补不超过 16 行，缺口必须在轮廓结束前闭合。
- 保留裁边、溢出、坏行、分裂与合并保护；大孔、开口裂缝、环形和 U 形不强行判为正常形状。

目标有效性使用原始颜色面积。

## 运算结构

行连接关系提前计算。帧级关联/平滑共享运算器先寄存操作数，再执行算术，每帧增加 54 个时钟，不改变像素接收节奏。
