## 验收口径

以全工程 `system_phy.area` 中最终布线后的 `#slice` 为首要指标。
最终 Slice 必须低于 18,929，LUT6、FF、ERAM、DSP 均不得超过上述基线。
门级 `#slice*` 只用于初筛，不与最终 Slice 混用；单项收益也不相加作为组合收益。

保留 1280×720、每拍四像素、RGB888 精度、十三种显示模式、颜色/形状四目标、
运动检测、稳定策略、四个 DDR 帧槽、冻结、完整 OSD 和延迟面板。
像素及结果发布拍数、时间精度、源帧对应和 CDC 握手保持。

## 实现内容与候选选择

候选编号延续 [原方案](SLICE_COMPRESSION_PLAN.md)，增加 G/H/I 三个在全链路审查中
找到、并经精确等价检查的机会：

| 编号 | 实现与功能约束 |
|---|---|
| A1 | 形状中心矩中的“条件取负再减”合并为完整 38 位受控加减，保留模运算、符号解释和 ready 拍。 |
| A2 | 互斥的 U/V 投影共用加减链，保留 V 偏移和原位宽。 |
| B | 分类、匹配、轨迹更新共用几何读地址及四字段 mux，分类等待期间地址保持。 |
| C | DDR 两份完帧计数共用一个计数器，保留 start 同拍 word 的两种统计口径与原完成边沿；独立模块默认仍用内部计数。 |
| D1 | 按原方案在 display、stage 1、stage 2 共用减法；初筛 LUT 代价偏大，未直接采用。 |
| D2 | display 复用原有 pending-age 值作为 total，原 stage 1 算 ISP，原 stage 2 算 total−ISP；全部为原时间位宽的模运算，三个输出仍在原拍发布。 |
| E | 颜色单框边界与四框坐标共用载荷，运动模式用同一区域；中心独立保留，通用模块默认保留完整独立字段，生产实例明确开启压缩。 |
| F | 标签避让分时比较，仿真等价但初筛 FF 增加 7，已撤回。生产 mixer 与本轮基线 SHA256 相同。 |
| G | AWB 按实际采样上界缩窄统计和除法余数；生产为 22 位 sum、14 位 count、23 位 remainder。40+40 拍除法、增益生效和 54 拍像素延迟保持。 |
| H | Scharr 四 lane 按梯度主次轴共享一套 106 倍阈值计算，保留精确边界、零梯度优先级、11 拍流水。 |
| I | 帧桥坐标先判 `value > MAX-offset`，再做窄位宽偏移加法；保留输入全部高位和精确饱和结果。 |

E 保留 valid=0/found=0 记录中的非零几何值、无 valid 时第四框回落、运动多框的
effect offset、独立中心、nonce、队列容量和四槽绑定。没有删减检测或用无效标志
替代 read 记录有效性。

此前试过的 PDPW 行缓存方案虽减少 ERAM，却增加 Slice，仍保持撤回状态。
本轮没有修改 DDR/HDMI 加密 IP 的内部实现。
