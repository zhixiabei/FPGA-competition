# HDMI 分区 RAW10 均值读数

用于固定位置的中心/四周偏色诊断。统计点在去马赛克和 AWB 之前，
保留传感器 RAW10 的十位数值；不从手机拍屏照片中反推 RGB。

当前默认 `SHOW_RAW_STATS=0`，HDMI 不显示九区测试表及其 E/G/AE 表头，
便于观察整幅图像。自动曝光和现有白平衡继续运行。
下面的取数步骤仅在需要再次诊断、主动开启测试表时使用。

## 上板与拍照

1. 将 `user_source/hdl_source/design_top_wrapper.v` 的 `SHOW_RAW_STATS` 设为 1，
   重新打开磁盘上的 TD 工程，再按原流程编译和下载。
   `raw_region_stats.v`、`raw_stats_osd.v` 在两份 `.al` 中都已登记。
2. 用均匀照亮的白纸或中性平面铺满摄像头画面，避开阴影、反光和光源本体。
3. 等摄像头写入完成、白平衡稳定及表头显示 `RAW10 LIVE`，拍清右侧整张表的 9 行数字。
   可以隔一两秒再拍一张，便于判断读数是否稳定。
4. 表中 `S` 列出现字母 S，表示该区至少一个 RAW 样本等于 1023，行文字会变橙色。
   这类数据不宜用于估计通道增益；降低照明或避免反光后重拍。

若主工程报 `raw_region_stats is a black box` 或 `raw_stats_osd is a black box`，
TD 当前加载的源文件清单缺少新增模块。已经打开的旧工程在保存/关闭时可能把
磁盘上补好的清单覆盖。在 TD 的 Tcl Console 执行以下命令，脚本会先关闭工程，
补回缺失条目，再重新打开并重启 `syn_1` 综合；不会生成或下载 bit：

```tcl
source D:/vivado_work/anlogic_edge_osd/verification/fix_raw_stats_in_td.tcl
```

表头 `R GR GB B` 分别是红、红行绿色、蓝行绿色、蓝通道，数值范围 0000～1023。
Gr 与 Gb 各自统计，不能先混成一个 G。黑电平未扣除，标定时需考虑传感器黑电平。
`WAIT` 表示还没收到完整帧；`STALE` 表示约两秒没有新的完整结果被显示，
此时保留旧数字供排查，不能把它当最新测量。S 只检测数值 1023，不能保证较低数值
一定未受到传感器内部限幅。

编号与画面位置对应如下：

```text
01 左上     02 上中     03 右上
04 左中     05 中心     06 右中
07 左下     08 下中     09 右下
```

每区统计 32×32 像素，四通道各 256 个样本，显示四舍五入后的整数均值。
1280×720 时，三列采样范围分别为 x=16～47、624～655、1232～1263，
三行分别为 y=16～47、344～375、672～703（坐标从零起）。
这九区用来判断色偏的方向、强度与对称性，不是整幅图像的密集平场标定。

## 更新与开关

测试表开启时，首行显示曝光诊断，例如 `RAW10 LIVE  E1991 G144 AL`，在暗光下可直接抄读数，
无需拍屏。E 是最近配置写完成的曝光控制码（四位），G 是增益档位（三位），
不是毫秒或增益倍数，也不是传感器寄存器回读。两个数字在 HDMI 帧边界成对切换。

| AE 状态 | 含义 |
|---|---|
| AL | 已收到完整 AE 统计，约两秒内仍有更新 |
| AW | 复位后尚未收到完整 AE 统计 |
| AS | 已收到过统计，但约 120 个 HDMI 帧没有新统计，保留旧值 |

RAW 的 LIVE 与 AE 的 AL 是两条独立统计路径；参数写完成本身不会把 AS 恢复为 AL。
2026-10-15 当前生产闭环范围为 E4..1991/G16..176，上电安全值 E1000/G16。
AL/AW/AS 仅说明统计是否持续更新，不是传感器寄存器回读或曝光收敛标志。
E/G 不是回读结果，实际画面仍需上板确认。
AW/AS 应检查完整帧统计；与曝光是否自动调节无关。
左上四个状态块全绿也不等于寄存器读回正确。

统计每个摄像头帧，表格在 HDMI 帧边界整体切换；同一张表中九区来自同一完整帧。
正常情况下每 16 个 HDMI 帧更新一次，60 Hz 时约 0.27 秒。
畸形行标志、缺少帧开始或截断帧不会提交新表格。
数字表是独立诊断快照，未与 DDR 当前显示图像的帧槽绑定；拍摄静止均匀目标后读数。
当前曝光按 LSC 前 RAW10 完整帧反馈调节，读数应在静止场景约 10 秒后观察。
RAW 九区统计和 AE RAW 测光都不受 AWB 输出增益直接影响。

`user_source/hdl_source/design_top_wrapper.v` 的 `SHOW_RAW_STATS` 默认设为 0。
设为 1 并重新编译下载可恢复测试表；测量完成后恢复为 0 并重新编译下载，
即可移除分区统计器、诊断跨时钟邮箱和数字表。AE RAW 测光、闭环控制及 AWB 保留，
K1 仍切换彩色/边缘。
表格只叠加在 HDMI 输出，不进入 RAW、AE/AWB 或 DDR 图像存储。

## 实现与验证入口

- `isp/raw_region_stats.v`：三组复用累加器，九区平均值仅用加法和移位计算，
  无除法器、乘法器、行缓存或帧缓存。
- `ae_stats_cdc.v`：复用已有握手邮箱，一次传输一个 45 位分区包，完整帧另发提交包；
  另一个 28 位邮箱传递曝光/增益写完成值和完整测光帧序号。
- `raw_stats_osd.v`：共用一个串行十进制转换器，两页小型数字存储器在帧边界切换，
  复用 `osd_char_lib` 字形，字符显示放大到 32×32 像素格；E/G 也复用该转换器。
- `sim/run_raw_stats.ps1`：分区数值、Bayer 排列、异常帧、实际 CDC 与 HDMI 逐像素检查。
  `-HdmiOnly` 只检查最终显示与邮箱，包括 E/G 成对更新、AL/AW/AS、帧序号环绕和复位。
- `verification/run_image_quality_build.ps1`：冻结源码到 TEMP，整机综合及布局布线，
  默认不生成 bit；`-GenerateBit` 可在最终时序通过后生成，脚本不下载。

仿真输出 `raw_stats_hdmi.ppm` 是合成读数的 HDMI 预览，不是实物标定数据。
