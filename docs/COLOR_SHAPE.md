# 颜色掩码与轻量形状识别

更新日期：2026-10-19。

当前实现先检测 K2 选中的颜色，再对该颜色的区域识别正方形、三角形和圆形。
红、绿、蓝共用一条颜色与形状流水线，每帧最多保留四个区域；
没有同时运行三套颜色检测器。K2 仍按 `RED -> GRN -> BLU -> MOV -> RED` 循环，
运动模式保留原运动总框，不做形状分类。

这是面向简单、实心色块的启发式分类，不是任意轮廓的几何证明。
它结合轮廓周长、面积、四方向投影及质心，支持画面内旋转的正方形、
不等边三角形。圆与正方形另用轴向、对角两组覆盖条件消歧，
没有仅凭一个正对外框的填充率分类。没有透视矫正，不能保证把明显梯形恢复为正方形、
把明显椭圆恢复为圆形。

## 数据路径

```text
AWB 后四像素 RGB
  -> 当前所选颜色掩码
  -> 3×3 多数滤波，去除孤立点
  -> 3×3 膨胀，再 3×3 腐蚀，修复小孔及少量小缺口
  -> 逐行区间与实际支持像素数
  -> 带原帧号的 FIFO
  -> 最多 16 个活动候选的连接、特征累积与退休
  -> 按支持像素数保留 Top4
  -> 共用串行形状描述器，依次分类四个候选
  -> 四轨迹确认、关联与漏检保持
  -> 原帧身份与实际 DDR 帧槽绑定
  -> HDMI 框与颜色、形状标签
```

主要实现位于 `user_source/hdl_source/isp/red_target_detect_96.v`：
`red_multi_run_engine` 累积区域特征，`color_shape_descriptor` 分类。
每个轨迹槽用两位保存形状，`O_multi_shapes[2*slot +: 2]` 与该槽的框、有效位、
保持位一起传递。形状随匹配候选更新；短暂漏检时保留最后确认的框与形状。
换色或进入、退出运动模式时清除颜色队列、轨迹和形状，随后重新确认。

形状元数据经过 `target_detect_switch_96.v`、`isp_top.v` 和顶层，
与 `target_frame_bridge.v` 的帧身份及 DDR 槽快照一起传输；
HDMI 在显示帧首锁存，避免上一帧的形状配上下一帧的图像或框。
原有显示偏移只调整框坐标，不改变形状代码。

K1 已加入四项可观察的中间结果：09 `BINARY` 是原始所选颜色掩码，
10 `EROSION`、11 `DILATION` 分别是原始掩码的 3×3 腐蚀、膨胀，
12 `CLOSE MASK` 是多数滤波加闭运算后的实际形状输入。
K2 选择红、绿、蓝时预览跟随该颜色；MOV 时预览默认红色掩码，
运动检测及运动框仍走原分支。所有 K1 模式都使用相同的清理掩码分类。
09 的二值化按颜色条件，不是按灰度阈值。

## 面积与近似周长

面积 `A` 是多数滤波和闭运算后实际命中的像素数，不是外框面积。
一行的区间为 `[L,R]`，宽度为 `w=R-L+1`。
同一四像素拍内的多个命中仍沿用原区间近似；如果命中数与区间宽度不一致，
该候选保留检测框，但形状标为未知。

周长以八分之一像素为单位保存为 `P8`，直向步长权重为 8，
对角步长权重为 11，即对角长度近似为 `11/8`。
这种近似比只统计水平、垂直边界的周长更适合旋转目标，
无需建立完整边缘图或逐像素追踪整个轮廓。

首行初始化为：

```text
P8 = 16*(w+1)
```

连接到相邻行时，设两行区间的水平重叠宽度为 `o`，
左右端点是否改变分别为 `dL`、`dR`，取值为 0 或 1：

```text
P8_new = P8_old + 8*(2+2*w-2*o) - 5*(dL+dR)
```

RTL 以“新行独立周长加已有周长，再减去共享边界”实现同一公式。
端点变化的修正把部分直角台阶换成加权对角步。
它是离散轮廓的近似周长；栅格量化、边缘噪声和滤波都会影响数值。
16 位周长的合并使用 17 位中间结果，溢出或下溢会锁存异常标记，
该区域后续不再输出确定形状。

## 分类与保护条件

分类主要比较 `Q=P8²/(64*A)`，实际使用交叉相乘，
没有执行除法或平方根。门槛如下：

| 输出 | 代码 | 周长、面积门槛 | 附加条件 |
|---|---|---|---|
| `UNK` | `00` | 未满足确定类别 | 保留有效颜色区域的框 |
| `SQR` | `01` | `13.5 <= Q <= 19` | 四方向范围近似相等、质心居中，且不满足圆覆盖条件 |
| `TRI` | `10` | `19 < Q <= 64` | 至少一个投影方向有足够质心偏移 |
| `CIR` | `11` | `Q <= 19` | 四方向范围近似相等、质心居中，且同时满足两组圆覆盖条件 |

这些数值对应当前周长近似、像素栅格和掩码清理，不是连续几何中精确的圆度常数。
低分辨率旋转方形的 Q 可能低于原 14.75 门槛，抖动圆的 Q 则可能高于原 14.5 门槛，
因此两类用以下双方向覆盖条件进一步区分。
不能仅凭“周长和面积落在三角形范围”就确认三角形；
细长矩形也可能有相似数值，因此增加以下投影检查。

每个候选保存 `x`、`y`、`u=x+y`、`v=x-y` 的极值，
以及两项双倍一阶矩：

```text
Mx2 = sum(2*x)，每行贡献为 w*(L+R)
My2 = sum(2*y)，每行贡献为 2*w*y
Mu2 = Mx2+My2
Mv2 = Mx2-My2
```

圆和正方形要求横、纵范围之比，以及两个对角范围之比，均不超过 `9/8`。
两个方向对共同限制长方形和明显椭圆，避免单靠一个轴向的宽高比判断。
对角范围在 RTL 中用带 `IMG_HEIGHT` 偏置的非负 `v` 坐标保存，
比较一阶矩时再消除偏置。

设 `Bxy=(xmax-xmin+1)*(ymax-ymin+1)`，
`Buv=(umax-umin+1)*(vmax-vmin+1)`，圆还须同时满足：

```text
25*A >= 18*Bxy
50*A >= 18*Buv
```

即在两组方向的投影外框内都达到约 72% 的覆盖；对角坐标使用双倍面积尺度。
旋转方形一般至少有一组覆盖率较低，圆则两组都较高。
这只对已经通过周长、范围、质心和轮廓有效性检查的候选消歧，
不取代主特征，也不能证明任意高覆盖区域一定是圆。
两个乘积串行复用原有乘法器，不新增 DSP。

对任一投影 `q`，定义投影跨度 `S=qmax-qmin+1`，
偏移量 `D=abs(Mq2-A*(qmin+qmax))`。
圆和正方形要求四个方向都满足 `16*D <= A*S`；
三角形要求至少一个方向满足 `12*D >= A*S`。
这利用简单实心三角形的非中心对称性，降低细长矩形被判成三角形的概率。
范围相近和质心居中仍不足以证明某个任意物体一定是正方形或圆形。

以下情况保守输出 `UNK`：

- 区间含有检测到的内部缺口，或同一候选出现同一行的多段合并。
- 一个新行段合并多个候选，或仅靠对角单点连接而没有水平重叠。
- 周长中间运算溢出，或已有异常标记。
- 外框宽或高不足 12 像素。原颜色候选的最低面积、最低宽高门槛仍然适用。
- 外框到达三层窗口的保护边界：`xmin <= 3`、`ymin <= 3`、
  `xmax >= IMG_WIDTH-4` 或 `ymax >= IMG_HEIGHT-4`。
- 描述值位于类别间隙、范围比例不合格，或质心条件不合格。

有孔洞、分叉、凹陷、接触和遮挡的色块不属于确定分类的目标输入。
由于原连接器每候选每行只保存一个合并区间，并非完整 CCL，
上述保护不能保证找出任意复杂图案的全部拓扑问题。
FIFO 或活动候选容量溢出仍报告 `OVF` 并使整帧检测结果无效，
与单个目标形状未知的 `UNK` 区分。

## 标签与上板输入

完整颜色标签示例为 `1 RED SQR OK`、`2 GRN TRI OK`、`3 BLU CIR OK`。
未知形状显示 `UNK`；漏检保持时末尾显示 `H`。
位置不足时使用 `1 SQR OK` 这样的紧凑标签，保留形状和状态；
仍找不到安全位置时只画框。运动标签沿用 `1 MOV OK` 或紧凑的 `1 OK`，
不显示形状。编号是轨迹槽编号，不是形状类别或面积排名。

建议先用纯色实心卡片或色纸，选择对应 K2 颜色，保证目标完整进入画面、
尺寸达到几十像素、与背景和其他同色目标明显分离。
先确认颜色框稳定，再验证旋转正方形、不等边三角形和圆形。
新目标连续匹配两帧后显示，漏检保持两帧。

颜色阈值、光照、曝光和 AWB 会直接改变掩码；高光变白、过暗、
背景同色或轮廓被遮挡时，形状描述也会随之变化。
当前绿色允许一定黄绿、青绿偏移；黄色、青色不作为独立检测颜色。
画面内旋转不要求物体边与图像边对齐；明显斜拍仍可能得到 `UNK`，
很尖细的三角形也可能超过当前描述范围。
清理针对小孔、少量窄缺口和轻微边缘抖动，密集缺口仍可能触发轮廓保护并显示 `UNK`。
约 20 像素的小圆若持续出现正负 1 像素的边缘抖动，特征可能与小方形重叠，
仍可能误判为 `SQR`；建议形状目标宽高达到几十像素后验收，不能把最低 12 像素门槛视为稳健识别尺寸。

## 资源与验证

颜色筛选、多数滤波、闭运算和区域连接继续共用。
颜色比较先求两个非主通道的最大/最小值，再共用比例、色相和差值比较；
五组差值参数、全部 16,777,216 个 RGB 组合的等价检查通过。
三个二值窗口各用一个 ERAM 打包保存两行历史，显示延迟仅传四位掩码，
末端才扩展成 RGB，避免复制彩色行缓存。
Top4 特征移入既有候选 ERAM 的地址 16..19，活动表仍为 0..15，
并通过保持 RAM 输出去除退休与分类的重复特征快照。
行段一阶矩乘法、共用串行形状描述器和随帧传递的 8 位形状代码保留。
形状描述器复用一套移位加法乘法过程，按顺序计算周长平方和四方向的比较乘积，
不为每个颜色或每个目标并行放置一套分类器。
内部位宽按周长平方、面积缩放及投影矩差的最大范围确定：
`max(32, COUNT_BITS+12, MOM_BITS+6, COUNT_BITS+COORD_BITS+6)`。
720p 使用 38 位，320×240 使用 33 位；每次乘法仍迭代 32 拍，
缩短位宽不改变单次乘法的周期；双方向覆盖增加两次串行乘法及控制拍。

没有新增 DDR 图像读写、整帧掩码或整帧边缘缓存；
分类时由原行段 FIFO 缓冲后续输入。
