# 颜色掩码与轻量形状识别

更新日期：2026-10-19。

当前实现先检测 K2 选中的颜色，再对该颜色的区域识别正方形、三角形和圆形。
红、绿、蓝共用一条颜色与形状流水线，每帧最多保留四个区域；
没有同时运行三套颜色检测器。K2 仍按 `RED -> GRN -> BLU -> MOV -> RED` 循环，
运动模式保留原运动总框，不做形状分类。

这是面向简单、实心色块的启发式分类，不是任意轮廓的几何证明。
它结合轮廓周长、面积、四方向投影及质心，支持画面内旋转的正方形、
不等边三角形。圆与正方形另用轴向、对角两组覆盖条件消歧，
没有仅凭一个正对外框的填充率分类。本版在方形证据充分时给投影范围增加两像素容差，
并对已确认圆形使用当前帧特征的双门槛保持，
没有透视矫正，不能保证把明显梯形恢复为正方形、把明显椭圆恢复为圆形。
近似方形的长方形和长短轴差别较小的椭圆也可能分别被标为 `SQR`、`CIR`。

## 数据路径

```text
AWB 后四像素 RGB
  -> 当前所选颜色掩码
  -> 3×3 多数滤波，去除孤立点
  -> 3×3 膨胀，再 3×3 腐蚀，修复小孔及少量小缺口
  -> 逐行区间与实际支持像素数
  -> 带原帧号的 FIFO
  -> 最多 16 个活动候选的连接、特征累积与退休
  -> 按支持像素数保留 Top4
  -> 共用串行形状描述器，依次分类四个候选
  -> 四轨迹确认、关联、形状连续两次确认与有限保持
  -> 原帧身份与实际 DDR 帧槽绑定
  -> HDMI 框与颜色、形状标签
```

主要实现位于 `user_source/hdl_source/isp/red_target_detect_96.v`：
`red_multi_run_engine` 累积区域特征，`color_shape_descriptor` 分类。
每个轨迹槽用两位保存形状，`O_multi_shapes[2*slot +: 2]` 与该槽的框、有效位、
保持位一起传递。目标框仍在连续两帧匹配后显示，形状单独进行时间稳定：
同一轨迹连续两次给出相同的非 `UNK` 类别，才确认该类别或切换到新类别。
新轨迹的第一帧同时记录待确认类别，因此干净稳定目标在第二帧出框时即可显示形状，
不会将框确认与形状确认顺序叠加成三帧。
单帧的异类或 `UNK` 不立即替换已确认形状；原类别再次得到支持时重新计时。
已确认的圆形可用下文 68% 的双方向覆盖继续支持 `CIR`，但仍须通过
当前帧的轮廓、周长、投影比例和质心检查。这不是无条件延长旧标签寿命。
连续两帧没有重获已确认形状的支持时保留旧类别，第三帧仍不稳定则清为 `UNK`，
防止旧类别长期停留。漏检会打断待确认类别的连续计数，目标框仍按原规则最多保持两帧。
确认和陈旧计数按来源帧结果推进；没有新的来源帧结果时，空闲时钟不会使类别老化。
HDMI 重复显示同一缓存帧也不会再次投票。
换色或进入、退出运动模式时清除颜色队列、轨迹和形状，随后重新确认。

形状元数据经过 `target_detect_switch_96.v`、`isp_top.v` 和顶层，
与 `target_frame_bridge.v` 的帧身份及 DDR 槽快照一起传输；
HDMI 在显示帧首锁存，避免上一帧的形状配上下一帧的图像或框。
原有显示偏移只调整框坐标，不改变形状代码。

K1 已加入四项可观察的中间结果：09 `BINARY` 是原始所选颜色掩码，
10 `EROSION`、11 `DILATION` 分别是原始掩码的 3×3 腐蚀、膨胀，
12 `CLOSE MASK` 是多数滤波加闭运算后的实际形状输入。
K2 选择红、绿、蓝时预览跟随该颜色；MOV 时预览默认红色掩码，
运动检测及运动框仍走原分支。所有 K1 模式都使用相同的清理掩码分类。
09 的二值化按颜色条件，不是按灰度阈值。

## 面积与近似周长

面积 `A` 是多数滤波和闭运算后实际命中的像素数，不是外框面积。
一行的区间为 `[L,R]`，宽度为 `w=R-L+1`。
同一四像素拍内的多个命中仍沿用原区间近似；如果命中数与区间宽度不一致，
该候选保留检测框，但形状标为未知。

周长以八分之一像素为单位保存为 `P8`，直向步长权重为 8，
对角步长权重为 11，即对角长度近似为 `11/8`。
这种近似比只统计水平、垂直边界的周长更适合旋转目标，
无需建立完整边缘图或逐像素追踪整个轮廓。

首行初始化为：

```text
P8 = 16*(w+1)
```

连接到相邻行时，设两行区间的水平重叠宽度为 `o`，
左右端点是否改变分别为 `dL`、`dR`，取值为 0 或 1：

```text
P8_new = P8_old + 8*(2+2*w-2*o) - 5*(dL+dR)
```

RTL 以“新行独立周长加已有周长，再减去共享边界”实现同一公式。
端点变化的修正把部分直角台阶换成加权对角步。
它是离散轮廓的近似周长；栅格量化、边缘噪声和滤波都会影响数值。
16 位周长的合并使用 17 位中间结果，溢出或下溢会锁存异常标记，
该区域后续不再输出确定形状。

## 分类与保护条件

分类主要比较 `Q=P8²/(64*A)`，实际使用交叉相乘，
没有执行除法或平方根。门槛如下：

| 输出 | 代码 | 周长、面积门槛 | 附加条件 |
|---|---|---|---|
| `UNK` | `00` | 未满足确定类别 | 保留有效颜色区域的框 |
| `SQR` | `01` | `13.5 <= Q <= 19` | 质心居中、不满足圆覆盖；通过原投影限制，或通过两像素容差且至少一组覆盖不超过 64% |
| `TRI` | `10` | `19 < Q <= 64` | 至少一个投影方向有足够质心偏移 |
| `CIR` | `11` | `Q <= 19` | 四方向范围近似相等、质心居中，且同时满足两组圆覆盖条件 |

这些数值对应当前周长近似、像素栅格和掩码清理，不是连续几何中精确的圆度常数。
低分辨率旋转方形的 Q 可能低于原 14.75 门槛，抖动圆的 Q 则可能高于原 14.5 门槛，
因此两类用以下双方向覆盖条件进一步区分。
不能仅凭“周长和面积落在三角形范围”就确认三角形；
细长矩形也可能有相似数值，因此增加以下投影检查。

每个候选保存 `x`、`y`、`u=x+y`、`v=x-y` 的极值，
以及两项双倍一阶矩：

```text
Mx2 = sum(2*x)，每行贡献为 w*(L+R)
My2 = sum(2*y)，每行贡献为 2*w*y
Mu2 = Mx2+My2
Mv2 = Mx2-My2
```

圆形继续要求横纵、两条对角方向的跨度之比均不超过 `9/8`。
正方形首先沿用该条件；若不满足，可在两个方向对中分别允许
`8*max_span <= 9*min_span + 16`，即原限制外再允许两像素跨度差。
这个额外分支还要求至少一组覆盖率不超过 64%，作为方形证据。
因此它能容忍小方块边缘量化，但不能让所有近圆、缺角或拉长目标一起进入宽松条件。
原有 65×55 长方形、半轴 35/30 椭圆和截去右侧九列的圆仍有拒绝回归。
对角范围在 RTL 中用带 `IMG_HEIGHT` 偏置的非负 `v` 坐标保存，
比较一阶矩时再消除偏置。

设 `Bxy=(xmax-xmin+1)*(ymax-ymin+1)`，
`Buv=(umax-umin+1)*(vmax-vmin+1)`，圆还须同时满足：

```text
25*A >= 18*Bxy
50*A >= 18*Buv
```

即在两组方向的投影外框内都达到约 72% 的覆盖；对角坐标使用双倍面积尺度。
旋转方形一般至少有一组覆盖率较低，圆则两组都较高。
这只对已经通过周长、范围、质心和轮廓有效性检查的候选消歧，
不取代主特征，也不能证明任意高覆盖区域一定是圆。
两个乘积串行复用原有乘法器，不新增 DSP。

当前帧还计算 `25*A >= 17*Bxy` 且 `50*A >= 17*Buv`，即两组覆盖均达到 68%。
只有已经确认为 `CIR` 的同一轨迹能使用这一较低门槛，并且该帧仍须满足
原 `9/8` 投影限制、质心、圆周长门槛和全部轮廓保护。新目标仍使用 72% 的确认门槛。
这样已经识别的圆在 72% 附近抖动时不会直接切成方形；真正换成有明显方形特征的目标时，
弱圆支持会失效，仍按连续两帧规则换类。破洞等异常帧从分类入口清除支持位，
不会沿用上一个候选的结果。四个候选各保留一位支持标志，跟随原关联使用。

对任一投影 `q`，定义投影跨度 `S=qmax-qmin+1`，
偏移量 `D=abs(Mq2-A*(qmin+qmax))`。
圆和正方形要求四个方向都满足 `8*D <= A*S`；
`D` 使用双倍一阶矩，因此对应实际质心到投影中心的距离不超过跨度的 `1/16`，
前版为 `1/32`。
三角形要求至少一个方向满足 `12*D >= A*S`。
这利用简单实心三角形的非中心对称性，降低细长矩形被判成三角形的概率。
范围相近和质心居中仍不足以证明某个任意物体一定是正方形或圆形。

以下情况保守输出 `UNK`：

- 区间含有检测到的内部缺口，或同一候选出现同一行的多段合并。
- 一个新行段合并多个候选，或仅靠对角单点连接而没有水平重叠。
- 周长中间运算溢出，或已有异常标记。
- 外框宽或高不足 12 像素。原颜色候选的最低面积、最低宽高门槛仍然适用。
- 外框到达三层窗口的保护边界：`xmin <= 3`、`ymin <= 3`、
  `xmax >= IMG_WIDTH-4` 或 `ymax >= IMG_HEIGHT-4`。
- 描述值位于类别间隙、范围比例不合格，或质心条件不合格。

有孔洞、分叉、凹陷、接触和遮挡的色块不属于确定分类的目标输入。
由于原连接器每候选每行只保存一个合并区间，并非完整 CCL，
上述保护不能保证找出任意复杂图案的全部拓扑问题。
FIFO 或活动候选容量溢出仍报告 `OVF` 并使整帧检测结果无效，
与单个目标形状未知的 `UNK` 区分。

## 前版质心容差的验证与取舍

六个实际 RGB 合成场景分别经过阈值、掩码清理和形状判断，
比较原门槛与最终门槛。两版投影范围比均为 `9/8`，
仅将实际质心偏移容差由跨度的 `1/32` 放宽为 `1/16`：

| 场景 | 原门槛 | 最终门槛 |
|---|---|---|
| 65×55 长方形 | `UNK` | `UNK` |
| 椭圆，半轴为 35、30 | `UNK` | `UNK` |
| 偏侧梯形，顶宽 53、底宽 65、高 65 | `UNK` | `SQR` |
| 方形缺去 17×24 的角 | `UNK` | `UNK` |
| 圆右侧截去 9 像素 | `UNK` | `UNK` |
| 居中梯形，顶宽 35、底宽 65、高 65 | `UNK` | `SQR` |

实验中同时放宽跨度会把表中长方形、椭圆、缺角方形和截断圆接收为确定形状，
因此最终只改质心门槛。梯形得到 `SQR` 体现对某些偏斜色块的容差，
不等于已恢复其透视或证明该物体原本为正方形。
这些是特定栅格化输入的回归结果，其他尺寸、倾斜、遮挡或光照仍需实际验证。
可在项目根目录运行 `sim/run_color_shape_geometry_compare.ps1` 重复三版本、共 18 项对照。

## 标签与上板输入

完整颜色标签示例为 `1 RED SQR OK`、`2 GRN TRI OK`、`3 BLU CIR OK`。
尚未确认或持续不稳定的形状显示 `UNK`；漏检保持时末尾显示 `H`。
形状时间稳定暂时保留旧类别时，若颜色目标本帧仍匹配，末尾仍为 `OK`；
`H` 只表示目标漏检保持，不表示单帧分类受到抑制。
位置不足时使用 `1 SQR OK` 这样的紧凑标签，保留形状和状态；
仍找不到安全位置时只画框。运动标签沿用 `1 MOV OK` 或紧凑的 `1 OK`，
不显示形状。编号是轨迹槽编号，不是形状类别或面积排名。

建议先用纯色实心卡片或色纸，选择对应 K2 颜色，保证目标完整进入画面、
尺寸达到几十像素、与背景和其他同色目标明显分离。
先确认颜色框稳定，再验证旋转正方形、不等边三角形和圆形。
新目标连续匹配两帧后显示，漏检保持两帧；形状按上节的独立确认与陈旧清除规则更新。

颜色阈值、光照、曝光和 AWB 会直接改变掩码；高光变白、过暗、
背景同色或轮廓被遮挡时，形状描述也会随之变化。
当前绿色允许一定黄绿、青绿偏移；黄色、青色不作为独立检测颜色。
画面内旋转不要求物体边与图像边对齐；质心门槛放宽只提供有限偏斜容差，明显斜拍仍可能得到 `UNK`，
很尖细的三角形也可能超过当前描述范围。
清理针对小孔、少量窄缺口和轻微边缘抖动，密集缺口仍可能触发轮廓保护并显示 `UNK`。
约 20 像素的小圆从未出现明确圆形证据时，仍可能与小方形重叠，首次被判为 `SQR`。
本版回归覆盖已确认圆叠加 ±0.5 像素八方向边界扰动后持续保持 `CIR`，
不保证任意噪声或从一开始就模糊的轮廓都能分类。建议宽高达到几十像素后验收，
不能把最低 12 像素门槛视为稳健识别尺寸。

## 方形像素容差与圆形特征保持回归

`sim/run_color_shape_camera.ps1` 使用生产面积门槛 128，所有形状由 RGB 输入产生，
不强制分类结果。44 帧、29 项检查覆盖：

- 有效尺寸 17×15 的轻微压缩方块：前版有框但连续 `UNK`，本版确认 `SQR`；旋转对照也为 `SQR`。
- 半径 10 的圆先确认，再加入 `0.5*cos(8*theta)` 的径向扰动：前版 `CIR→SQR→CIR`，本版持续 `CIR`。
- 连续四帧弱圆证据不会被原三帧陈旧机制清为 `UNK`；真正换成方形仍在第二帧切换。
- 随后加入 17×17 内孔，第三帧清为 `UNK`，证明轮廓无效时不会继承旧支持位。
- 约 12 像素目标的颜色面积限制仍适用；较大长方形仍拒绝，较大方形及带扰动圆仍通过。
- 四个目标面积排序变化后分别保持圆、清为未知、切成方形、保持圆；清除后弱圆不能继承旧轨迹的资格。

这是针对可复现判据缺陷的合成回归，尚未获得用户摄像头的实际掩码，不能把它等同于实拍验收。

## 资源与验证

颜色筛选、多数滤波、闭运算和区域连接继续共用。
颜色比较先求两个非主通道的最大/最小值，再共用比例、色相和差值比较；
五组差值参数、全部 16,777,216 个 RGB 组合的等价检查通过。
三个二值窗口各用一个 ERAM 打包保存两行历史，显示延迟仅传四位掩码，
末端才扩展成 RGB，避免复制彩色行缓存。
Top4 特征移入既有候选 ERAM 的地址 16..19，活动表仍为 0..15，
并通过保持 RAM 输出去除退休与分类的重复特征快照。
行段一阶矩乘法、共用串行形状描述器和随帧传递的 8 位形状代码保留。
形状描述器复用一套移位加法乘法过程，按顺序计算周长平方和四方向的比较乘积，
不为每个颜色或每个目标并行放置一套分类器。
内部位宽按周长平方、面积缩放及投影矩差的最大范围确定：
`max(32, COUNT_BITS+12, MOM_BITS+6, COUNT_BITS+COORD_BITS+6)`。
720p 使用 38 位，320×240 使用 33 位；每次乘法仍迭代 32 拍，
缩短位宽不改变单次乘法的周期；双方向覆盖增加两次串行乘法及控制拍。

没有新增 DDR 图像读写、整帧掩码或整帧边缘缓存；
分类时由原行段 FIFO 缓冲后续输入。

长方形、椭圆、空心和分叉图案、四目标关联、保持、清除及生产分辨率大坐标。
本次最终检测器在两种 RAM 各通过 109 个结果、217 项检查，
720p 通过 111 个结果、223 项检查；均含 30 个真实 RGB 小孔/边噪用例与 3 个新增容差探针。
三版本对照另通过 18 项检查，最终列使用原样复制的最终检测器。
时间专项在两种 RAM 各通过 52 个结果、59 项检查、50 个受控步骤，
保留真实 RGB、候选关联与 K2 路径，仅在描述器最终类别输出注入预定序列；
包含连续确认、单帧抖动、换类、第三帧清为未知、四槽独立、模式/错误清理，
以及 1,000 个空闲时钟内全部形状稳定状态不推进。
它不把受控类别序列视为真实轮廓噪声的物理模型。
ISP 集成在三帧内确认四条稳定轨迹、输出八个 `SQR` 框，
保持干净目标第二帧出框即可带形状的行为。完整日志与实际执行快照见
