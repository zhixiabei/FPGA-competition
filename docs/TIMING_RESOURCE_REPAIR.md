## 修改实现

### 颜色检测前端

原来同一拍完成 SOF 模式旁路、RGB 通道选择、次通道最大/最小值、
阈值运算和掩码行存储器输入。现在将通道选择与最大/最小值登记，
下一拍完成原阈值判断，保持每拍四像素。

valid、起帧、末拍、坐标、预览模式、frame ID 同步经过新增寄存级。
多目标 clear 同步延后一拍，使其与原引擎输入、帧身份和结果一致。
早到 SOF、SOF 与首个有效拍重合、空拍和连续帧的接受规则均保留。
特殊 `RED_DELTA` 参数仍保留原来的九位加法截断行为。

预览尾部原有六级四位延迟缩短为五级，抵消前端新增一拍。
所有掩码预览的显示延迟仍为 11 拍，RGB 图像通路不增加延迟。
单目标和多目标计算结果相对基线晚一拍；720p 三目标测试最大
EOF 到 ready 为 1216 拍，基线为 1215 拍。

### CNN 控制与缓存返回

原实现遇到激活缓存未命中后，`ACT_RUN` 在非末项没有返回 `RUN`；
term 和卷积坐标继续推进，而 MAC 有效条件只接受 `RUN` / `DRAIN`，
导致漏掉乘加项。独立数值测试复现了输出错误：
`channel=0 pos=2 got=-32768 expected=32767`。

修复后，每个返回项发出后进入正常运行态。
缓存命中和缓存返回共用一次 term/kx/ky/channel_offset 更新。
模型 ROM 的组地址直接使用 `active_group` 寄存器，在运算完成时清零，
去掉 state 译码经模型 ROM 返回缓存命中判断的长反馈链。

保留 24 路 DSP、A12/W8 数值、54 位累加、权重尾部 RAM、池化、
偏置、移位、饱和和 ReLU。未增加流水级。
在接收到启动信号的原有 IDLE 边沿锁存卷积核、步长是否为二、padding、
输入宽高和源平面大小。实际模型 ROM 的 16 项配置中，这些字段在同一
operation 的全部组内相同。组相关的权重地址、系数地址和输出地址仍实时更新。
这将 operation→模型 ROM→地址→缓存命中→计数器推进的反馈路径隔开，
启动、取数和推理状态机均不增加拍数。

23 个数值与背压测试的周期数、MAC 数和 DDR 读写事务量，
与“只修复漏返回”的最小功能参考完全相同。
不拿存在漏算的原版作为速度基准。

### HDMI 同步字模

原共享字库是组合译码，坐标到面板选择、字符选择、字模译码、
叠加优先级和 RGB 输出经过一条长组合路径。
新增一块 1024×16 同步字模 ROM，保存原字形，使用 1 块 ERAM。
原 `osd_char_lib` 组合模块保留，供原有计数器等消费者继续使用。

将原输出边沿登记的 RGB 拆成底色、字色、字有效和列位置上下文，
与同步字模输出同拍，末端只选择字模位和颜色。
HS、VS、DE、DDR 读使能和显示帧开始信号保持原拍。
runtime 状态仍在原像素输出边沿采样，没有改成整帧锁定。
实时状态在两个时钟沿之间变化时，不会直接穿透到 RGB 输出。

保持原面板优先级、字符位置、全部水果/状态文字、中文、
调试模式、字色和背景色。所有外部像素和控制信号对照原版验证。

首轮“直接八位 runtime 字符选择”虽通过功能测试，
但整机 LUT 和综合时序反而变差，未采用；
正式同步 ROM 版本使用原 runtime 字符串选择逻辑。

### 标签布局

候选标签的位置与右、下端点并行计算，保持原有 13 位算术截断和画幅边界规则。
当前目标的四个边界用 48 位寄存器缓存：起帧时捕获第零目标，
处理完一个目标的原有边沿同时预取下一个目标。
布局判定不再串联“目标槽选框→端点算术→面板与标签避让”。

保留全部 32 次位置尝试、完整与紧凑文字、固定面板避让、
已接受标签之间的避让和目标有效性检查。
没有增加布局周期；四槽接口的最坏布局时间仍为 128 拍。
标签位置、视频输出和帧切换逐拍对照保持一致。

### 运动结果稳定

锚框更新时同步保存其宽、高、横纵中心和，均为原来的 13 位精度。
宽高复位为一，三处原有锚框更新均更新缓存，含无效候选触发释放的分支。
关联判断不用重复从存储坐标计算特征。

中心绝对差改为一次 14 位有符号差值和上下界比较。
阈值继续保留原 `2*MAX_CENTER_STEP` 的 32 位无符号比较语义，
含大参数乘法截断；没有缩窄阈值。
确认、释放、支撑密度、尺寸、交叠、框坐标排序保护和发布周期均保留。

平滑坐标仍按原方向作四分之一步进并保留死区。
原来的 `previous + ((current-previous+bias) >>> 2)` 改写为
`(3*previous + current + bias) >> 2`；
`current >= previous` 时 bias 为三，否则为零。
14 位无符号加法最大值为 16383，结果取 `[13:2]`。
三倍旧值与当前值偏置可并行计算，避免“求差→偏置→回加”串联。
原有有符号死区比较、四个坐标排序保护和逐拍状态全部保留。
通过原版 HDL 差分，并对六种死区参数逐一穷举全部 4096×4096 坐标对。
