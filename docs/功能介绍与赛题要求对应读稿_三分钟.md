# 功能介绍与赛题要求对应读稿（三分钟）

修订日期：2026-11-02。根据当前工程功能和已读取的赛题 PPT 整理，补充 Gamma 校正。以下为约三分钟的口播正文，最终时长随语速和演示停顿变化。

各位老师好，我们的作品是《基于安路 FPGA 的实时图像处理与智能称重计价系统》。下面结合赛题要求，介绍系统的主要功能。

系统采用赛题指定的 HX1P35A 开发板，以安路 PH1P35 为核心，通过 MIPI 摄像头采集视频，在 FPGA 内完成处理，经过 DDR2 缓存后，通过 HDMI 输出。当前配置为 1280×720、60 Hz 显示时序，构建了从采集、处理到显示的完整通路，对应视频采集与结果输出的基础要求。

图像处理方面，通过 K1 按键，可以循环切换十三种显示模式，包括彩色 Gamma、灰度、边缘检测、负片、浮雕、颜色保留、卡通化，以及二值和多种形态学显示。这对应基础图像处理、扩展要求中的视觉增强，以及进阶要求中的多算法切换与状态显示。

输出画面还叠加了安路 Logo、模式名称和检测结果，对应 OSD 信息叠加要求。模式在帧边界更新，减少切换时的画面异常。

图像质量方面，系统加入自动曝光、自动白平衡、LSC 镜头阴影校正和 Gamma 校正，分别用于调节曝光、改善偏色、补偿暗角，以及调整画面的亮暗层次。其中，Gamma 在彩色显示模式下通过固定查找表实现。自动曝光和白平衡对应图像质量自动调节，LSC 和 Gamma 则体现视觉增强。

目标识别方面，系统支持红、绿、蓝颜色检测，以及正方形、圆形和三角形识别，并显示检测框、中心标记和形状标签。检测框随物体位置更新，对应目标检测与识别、目标跟踪与信息标注。当前采用单目标方案。

实际应用方面，打开 SW2 后，FPGA 内的定点卷积神经网络对固定区域中的苹果、香蕉、葡萄、橘子和草莓进行分类。结合 HX711 称重模块，完成去皮、校准和重量采集，再根据水果类别及预设单价计算金额，显示重量和总价。结果稳定后，语音模块自动播报，同一结果避免重复播报。这对应面向实际应用场景的系统设计。

系统还通过帧差方法检测运动区域，叠加运动提示框，对应运动目标检测。打开 SW1，可以查看总延迟、ISP 延迟和缓存等待延迟，对应处理延迟可视化。这里测量的是板内数字通路，不包含曝光和显示器响应时间。

自主创意方面，当前源码加入了镜头签名。打开 SW3 后，系统跟踪红色标记，将移动轨迹绘制成笔迹，支持镜像显示、暂停书写和退出清空，对应自主创新要求。

性能方面，我们采用四像素并行流水线、行缓存复用和定点计算，控制资源与处理开销，对应系统性能优化。上述功能已整合到同一主工程，并有局部验证记录，最新版本仍需完成最终布局布线、固化和上板验收。

以上是我们的功能介绍，谢谢各位老师。
