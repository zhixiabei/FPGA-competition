# 功能介绍与赛题要求对应读稿

依据：用户提供的《赛题解析二  (1)(1).pptx》及 2026-11-01 当前统一工程源码、工程说明。

使用说明：以下按约 8 分钟的功能汇报撰写。当前源码已经整合相关功能，并有工程说明记录的局部仿真与部分局部综合结果，但最新统一版本尚未完成最终布局布线和上板验收，现有旧 bit 不包含镜头签名。正文使用“当前设计支持”等表述，不将源码实现写成最终实测通过。

## 可直接朗读的正文

各位老师好，我们的作品是《基于安路 FPGA 的实时图像处理与智能称重计价系统》。作品围绕安路赛道选题二，在视频采集、图像处理和显示的基础上，加入颜色与形状识别、水果分类、称重计价和语音播报，并扩展了镜头签名功能。下面我结合赛题要求，介绍当前设计。

首先是系统整体架构。我们采用赛题指定的 HX1P35A 开发板，以安路 PH1P35MDG324 为核心。摄像头通过 MIPI 接口输入 RAW10 视频，FPGA 完成数据解包和图像预处理，再经过 DDR2 帧缓存，通过 HDMI 输出。当前工程采用 1280×720 的图像尺寸，配置 60 Hz 的显示时序，主要图像处理和识别计算都在 FPGA 内完成。

这条完整的视频通路，对应基础要求第一项“视频采集与显示”和第三项“处理结果稳定输出”。我们在设计中处理了跨时钟传输、完整帧缓存以及图像与检测结果的对应关系，重点保证输入、处理和输出之间能够正确衔接。最终的连续运行稳定性，还需要在最新整合版本上完成实测。

第二部分是图像处理。当前通过 K1 按键，可以循环切换十三种显示模式，包括带 Gamma 校正的彩色显示、灰度、Scharr 边缘检测、负片、浮雕、颜色保留、卡通化、反色边缘、形态学边缘，以及颜色掩膜的二值、腐蚀、膨胀和闭运算显示。切换时，画面还会显示当前模式名称。

其中，灰度、边缘检测和二值处理对应基础要求第二项。卡通化、浮雕、颜色保留等效果，对应扩展要求第一项“视频风格化与视觉增强”。通过按键选择算法、显示当前状态，并让模式在帧边界生效，对应进阶要求第一项“多算法切换与状态显示”。

第三部分是信息叠加。我们在输出视频中叠加了安路 Logo、算法名称，以及相应模式下的目标框、形状标签或水果计价信息。这对应基础要求第四项，也使处理结果能够直接通过画面观察。

接下来是颜色和几何形状识别。关闭水果功能后，K2 可以在红色、绿色、蓝色和运动检测之间切换。颜色检测根据像素的颜色特征提取目标，再计算目标范围，在画面中叠加检测框和中心标记。当前形状分支支持正方形、圆形和三角形，条件不充分时输出未知类别。

目标移动时，检测框会随位置更新，设计中还加入了连续确认和位置平滑。这部分对应扩展要求第二项“目标检测与识别”，也对应进阶要求第二项“目标跟踪与信息标注”。当前采用单目标方案，演示时需要选择颜色明显、背景干扰较少的物体。

运动检测对应进阶要求第四项。我们采用相邻帧的灰度块差异寻找变化区域，并结合邻域支持、连续确认以及全局亮度变化抑制，减少孤立噪声和曝光变化造成的误检。检测结果以一个合并框显示，主要面向固定摄像头下的物体运动。

在实际应用方面，我们重点设计了水果识别与智能称重计价。打开 SW2 后，系统对固定识别区域中的水果进行分类，当前支持苹果、香蕉、葡萄、橘子和草莓五类。识别输入来自显示特效之前的彩色图像，避免将边缘图或卡通图作为分类输入。分类器使用 FPGA 内的定点卷积神经网络，结合背景比较和结果确认，处理空场景与标签抖动。

称重部分接入 HX711。使用时先进行去皮，再用 227 克参考物完成校准。系统根据水果类别选择对应单价，将重量换算为金额，并把重量和总价叠加到 HDMI 画面中。当前设置的单价分别为苹果每千克 8 元、香蕉 6 元、葡萄 12 元、橘子 5 元和草莓 20 元，总价四舍五入到分。

我们还接入了 CX-SP5T 语音模块。当有效重量和金额满足稳定条件后，自动播报称重结果与总价，同一结果只播报一次，取走物品并重新放入后可以再次播报。没有有效识别、尚未校准或传感器异常时，不启动新的有效计价播报。

这样，图像识别结果就能进一步参与计价，并驱动语音模块完成输出，对应扩展要求第三项“面向实际应用场景的系统设计”。整个应用面向桌面水果称重与计价演示。

自主创意方面，当前源码加入了镜头签名。打开 SW3 后，画面水平镜像，系统跟踪明显的红色标记，将移动轨迹叠加成红色笔迹。SW4 可以暂停落笔并保留已有笔迹，关闭暂停后继续书写，退出签名时清空画布并恢复此前的显示模式。目标丢失或坐标大幅跳变时会断笔，减少不合理的连线。这部分对应扩展要求第五项。

实时性方面，我们加入了延迟可视化面板，对应进阶要求第三项。打开 SW1，可以查看同一帧的总延迟、ISP 处理延迟，以及缓存与输出等待延迟。面板测量的是 RAW 输入到 HDMI 输出的板内数字通路，不包含摄像头曝光时间和显示器响应时间。通过分段读数，可以进一步分析等待主要发生在哪个环节。

图像质量方面，设计中包含自动曝光、自动白平衡、LSC 镜头阴影校正，以及彩色显示模式下的 Gamma 校正。自动曝光根据图像亮度统计调节曝光与增益，白平衡调整颜色通道比例，LSC 改善画面不同位置的亮度和颜色一致性，Gamma 通过查找表调整亮暗层次。自动曝光和自动白平衡对应进阶要求第五项“图像质量自动调节”，LSC 与 Gamma 则体现扩展要求第一项中的视觉增强。

性能优化方面，我们采用四像素并行流水线、行缓存复用和定点计算，并让视频与识别共享 DDR 资源。签名画布使用片内单色位图保存笔迹，控制新增存储和带宽开销。这些措施对应扩展要求第四项“系统性能优化”，最终的资源占用、时序和功耗仍以完整实现和实测为准。

最后说明当前整合状态。上述功能已经纳入同一主工程，通过按键和拨码开关选择，按赛题要求组织为一个完整设计。模型支持上电从独立 Flash 自动加载和校验。后续还需要完成最新版本的最终布局布线、配置固化，以及断电重启和整机稳定性测试，验证上电运行和各模式切换。

我们的设计将实时图像处理与水果称重计价结合起来，并通过检测标注、语音输出和镜头签名展示不同的交互方式。以上是当前功能及其与赛题要求的对应情况，谢谢各位老师。

## 赛题要求对照

本表的“对应”表示当前源码中的功能覆盖关系，不表示已经完成最终板级验收。赛题第 5 页要求基础项至少实现 3 条，第 6 页要求扩展项至少实现 1 条。

| 赛题项目 | PPT 页码 | 当前功能对应 | 汇报时的准确表述 |
|---|---|---|---|
| 基础 1：MIPI 采集、HDMI 输出 | 5、16 | MIPI RAW10 接收、解包、ISP、DDR2、HDMI | 工程配置 1280×720 图像与 60 Hz 显示时序，实际有效采集帧率需实测 |
| 基础 2：至少一种 FPGA 图像处理 | 5、17 | 灰度、Scharr 边缘、二值及其他处理 | 已有多种硬件算法，不能将十三种显示模式都称为十三种独立算法 |
| 基础 3：处理结果稳定连续显示 | 5、16 | 帧缓存、跨时钟传输、帧对应与 HDMI 时序 | 具备相应设计和局部回归记录，最新整机稳定性待上板验收 |
| 基础 4：OSD 与安路 Logo | 5、18 | Logo、模式名称、检测框和分类计价信息 | 各信息按当前模式显示，并非所有面板同时出现 |
| 扩展 1：风格化或视觉增强 | 6、20 | 卡通化、浮雕、颜色保留、形态学边缘，以及 LSC 与 Gamma 校正 | Gamma 为彩色模式下的固定查找表色调校正，不是自适应 Gamma |
| 扩展 2：目标检测与识别 | 6、21 | 颜色目标、三类几何形状、五类水果分类 | 当前颜色/形状为单目标，水果为固定区域分类 |
| 扩展 3：实际场景与外设联动 | 6、22 | 水果识别、HX711 称重计价、CX-SP5T 语音 | 图像识别结果参与计价并驱动语音模块 |
| 扩展 4：性能优化 | 6、22 | 四像素并行、流水线、行缓存复用、定点推理、共享 DDR | 介绍已采用的结构，最终资源、时序和功耗待完整验证 |
| 扩展 5：自主创意 | 6、22 | 红色标记镜头签名、镜像、暂停与清空 | 已纳入源码且有局部验证记录，当前旧 bit 不包含此功能 |
| 进阶 1：多算法切换与状态显示 | 23 | K1 循环十三种显示模式，叠加模式名称 | 模式配置在帧边界生效 |
| 进阶 2：目标跟踪与标注 | 24 | 单目标框、中心标记、形状标签、位置平滑 | 简单目标的位置跟随，不能表述为通用多目标身份跟踪 |
| 进阶 3：处理延迟可视化 | 25 | SW1 显示 TOTAL、ISP、BUF | 只测板内数字通路，当前面板不显示 FPS |
| 进阶 4：运动检测 | 25 | 8×8 灰度块帧差、邻域筛选、连续确认、单个合并框 | 固定摄像头场景，不具备摄像头运动补偿 |
| 进阶 5：图像质量自动调节 | 25 | 自动曝光、自动白平衡及镜头阴影补偿 | 当前已接入 AE/AWB，不能额外宣称已实现直方图均衡 |
| 指定开发板 | 5、26 | 当前 PH1P35MDG324 主工程及板级约束 | 采用 HX1P35A 平台 |
| 功能整合为一个最终设计 | 26 | 同一主工程包含相关模块，按键/拨码切换 | 源码已经整合，最终统一 bit 仍需构建验收 |
| 固化并上电运行 | 26 | 模型由 U30 自动加载和校验，配置程序使用独立配置 Flash | 模型自加载已有设计，最终主程序固化与断电重启验收尚待完成 |

## 演示操作提示

以下用于准备现场操作，不需要逐条朗读。最新统一 bit 完成构建并通过上板验证后，再按此顺序录制或展示。

| 顺序 | 操作 | 介绍重点 |
|---|---|---|
| 1 | SW2、SW3 关闭，先展示彩色视频 | 视频采集、处理、缓存和输出的完整通路 |
| 2 | 按 K1 切换灰度、边缘、卡通等效果 | 基础算法、视觉增强、多模式状态显示 |
| 3 | 保持 SW2 关闭，按 K2 切换红、绿、蓝 | 单目标检测框、中心标记及几何形状标签 |
| 4 | K2 切换至运动检测，固定摄像头移动物体 | 帧差运动区域与稳定处理 |
| 5 | 打开 SW1 | TOTAL、ISP、BUF 的含义与测量范围 |
| 6 | 空识别区域建立背景后打开 SW2，空秤去皮，用 227 g 参考物按 K3 校准 | 先完成识别与称重准备，校准参数掉电不保存 |
| 7 | 将水果放入固定识别区域并称重，等待稳定播报 | 水果类别、重量、金额与语音的联动 |
| 8 | 关闭 SW2，打开 SW3，用明显红色标记书写，切换 SW4 暂停与继续，最后关闭 SW3 | 镜像签名、保留笔迹、断笔与退出恢复 |
