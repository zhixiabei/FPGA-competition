# 多颜色目标与形状检测

更新日期：2026-10-19。当前生产源码默认 `RED_MULTI_ENABLE=1`，
主工程为 `td_project/anlogic_edge_osd.al`，顶层为 `design_top_wrapper`。
本版由 K2 选择红、绿、蓝主色，并复用有限容量的行程段连接、最多四条独立轨迹和四框显示；
在所选颜色掩码上累计面积、近似轮廓周长和投影特征，识别正方形、三角形、圆形。
帧差运动分支仍输出一个总框。它不是完整的连通域标记算法，也不识别物体类别。

本轮加入 K1 掩码预览、闭运算与特征存储压缩。
实际发布资源见本页资源章节；算法说明见[颜色与形状检测](COLOR_SHAPE.md)。
烧录时重新加载 `td_project/anlogic_edge_osd_Runs/best_result/anlogic_edge_osd.bit`；
`firmware/anlogic_edge_osd.bit` 是同内容副本。版本和文件校验值以
[发布清单](../build/release/release_manifest.json) 为准。

## 操作与画面

- 上电为 `00 COLOR GAMMA` 和红色检测。**K1（D5）**单向循环十三种显示模式，
  **K2（A9）**按红色、绿色、蓝色、运动循环；K3（B9）、K4（C7）无操作。
- K1/K2 按下和释放均消抖 20 ms，长按只触发一次。模式在摄像头帧首生效，
  显示配置及检测结果随实际 DDR 帧槽传到 HDMI。
- 颜色检测最多显示四个框，轨迹槽 1/2/3/4 分别为红、青、黄、绿。
  完整跟随标签例如 `1 RED SQR OK`，颜色为 `RED/GRN/BLU`，
  形状为 `SQR`（正方形）、`TRI`（三角形）、`CIR`（圆形）或 `UNK`（未知）。
  漏检保持时末尾为 `H`；空间不足时退化为 `1 SQR OK` / `1 SQR H`，
  仍保留形状。找不到安全位置时省略该标签，仍保留框。
- 标签尝试放在框附近，避开已有固定 OSD、延迟面板及其他跟随标签。
  左下角显示 `RED/GRN/BLU COUNT:0..4`；容量溢出时显示 `OVF`，该帧不画框。
  运动模式显示 `MOV COUNT:0..1` 和一个运动总框，标签为 `1 MOV OK`。

编号表示固定轨迹槽，不是当前帧面积排名，也不是物体类别。
无法可靠分类的颜色区域仍出框，形状标为 `UNK`；形状判断不筛掉颜色目标。
先用彼此分离、尺寸足够的两到四个当前所选颜色物体验证；稳定出现两帧后才显示新框。
短暂漏检时保持原框两帧，第三个漏检帧清除。
K2 换色或进入/退出运动时清除颜色队列和轨迹，重新确认后显示，避免旧结果复活。
检测仍读取 AWB 后、显示效果前的 RGB，因此十三种显示模式均可叠加相同的颜色检测。
模式 09/10/11 分别预览原始所选颜色掩码及其腐蚀、膨胀，12 预览实际形状输入：
3×3 多数滤波 → 3×3 膨胀 → 3×3 腐蚀。MOV 时预览默认红色掩码。
形状判断固定使用清理结果，不随 K1 预览模式改变。

## 实际算法

```text
AWB 四像素 RGB
  -> K2 选择红/绿/蓝主通道
  -> 共用主通道判定；绿色使用较宽的黄绿/青绿范围
  -> 3×3 多数滤波
  -> 3×3 膨胀，再 3×3 腐蚀（闭运算）
  -> 行程段与带帧号 FIFO
  -> 16 项候选连接/退休，同时累计面积、周长和投影特征
  -> 合格区域中支持像素最多的四个
  -> 共用串行形状描述器，判定 SQR/TRI/CIR/UNK
  -> 四轨迹匹配、确认和保持
  -> 原帧/DDR 槽绑定
  -> 四框和颜色/形状跟随标签
```

1. 复用 `red_target_detect_96.v` 的全分辨率掩码、3×3 多数滤波及闭运算，
   不是先缩为 160×90 块图。生产颜色门槛为 `RED_MIN=24`、`RED_DELTA=6`，
   红、蓝保留严格的通道比例与主色色相筛选；绿色允许偏黄绿和偏青绿，
   要求红、蓝各不超过绿色的 80%，同时仍满足亮度和通道差门槛。
   三层窗口各用一个 ERAM 打包保存两行一位掩码，最外侧三像素不参与可靠分类。
   多数滤波去除孤立点，闭运算修复小孔和少量小缺口；密集锯齿或大缺口仍可能为 `UNK`。
2. 将连续有命中的四像素拍合成行程段，记录首末命中坐标、行号及实际过滤命中数。
   同一四像素拍内有间隙的命中按一个段近似处理，因此不保证分开四像素拍内部的邻近小目标。
3. 深度 64 的 FIFO 保存 `RUN/END/OVERFLOW/ABORT` 描述符及 10 位原帧号，
   为结束和错误标记保留空间；后续帧首不会把正在排队的上一帧结果改成新帧。
4. 串行扫描最多 16 个活动候选，按同一行/相邻行区间相交及相邻一像素连接。
   每项只保留当前行和前一行的一个合并区间；已不可能继续连接的候选退休。
   退休时要求过滤命中数至少 128、宽和高至少 8 像素，保留支持像素最多的四个合格候选。
5. 周长从相邻行段的宽度、重叠和端点变化近似累计，使用轴向权重 8、
   斜向权重 11。帧结束后，只对 Top4 串行计算周长平方与面积关系，
   再用 x、y、x+y、x-y 四方向跨度和一阶矩作保护判断。
   分类以面积、周长、投影和质心为主，不单独建立整幅边缘图。
   形状码每槽 2 位：`00 UNK`、`01 SQR`、`10 TRI`、`11 CIR`。
6. 四个轨迹槽按最近邻距离逐对做一对一关联。新目标第一帧只建轨迹，
   下一帧匹配后确认；已确认轨迹允许漏检两帧。坐标直接跟随匹配候选，
   不采用运动分支的四分之一平滑策略。形状随相同轨迹槽更新和保持，
   无效槽的形状码清零；换模式会一并取消正在计算的形状结果。

候选表和 FIFO 使用安路同步 ERAM 封装；候选读取与判断分级，
避免把 RAM 输出、行判断、区间相交和边界写入串在同一拍。
Top4 特征存放在既有候选 ERAM 的 16..19 地址，活动候选仍使用 0..15，
不为四个目标复制特征寄存器。退休与分类阶段保持 RAM 输出稳定，去除重复快照。
没有新增 DDR 图像读写、整帧标签图或独立算法时钟。四个目标共用一个
移位累加乘法器计算帧级描述量，新增开销仍以最终资源报告为准。

## 容量与识别边界

本版是有限容量的扫描线区域连接，**不是完整 CCL**。
单候选每行只有一个合并区间，不能记录同一连通区域在该行的多段空隙。
例如 U 形、环形或分叉区域的两个臂可能形成一个宽区间，
间隙内的独立红目标可能被一起合并。需要严格区分这类区域时，
应实施保存全部行段和等价标签的完整 CCL；原方案见
[连通区域设计规划](CONNECTED_COMPONENTS_PLAN.md)。

形状识别面向填实、彼此分离、边界清楚的简单色块，支持图像平面内旋转的
正方形及普通不等边三角形，不要求三角形必须等边。
未做透视矫正：严重斜拍的正方形、圆形会变形，不能保证仍分为原形状。
形状宽、高均须至少 12 像素；太小、接触画面边缘、内部空洞、同一行多段、
候选合并或周长异常时保守标为 `UNK`，颜色框仍可保留。
长方形、椭圆没有独立类别；代表性长方形、椭圆、空心环和十字场景已检查为
`UNK`，但该有限特征分类器不能保证拒绝所有任意形状。

16 项限制是同时活动候选数，不是全帧物体总数。FIFO 满或活动候选耗尽时，
整帧结果无效，清除该帧框和轨迹并报告 `OVF`；
不会把未完成的局部结果或原单总框冒充四目标结果。
超过四个合格区域但未触及容量限制时，只输出四个最大候选。
复杂噪声、密集行段可触发溢出，不能将四个简单矩形的吞吐测试视为任意图案的最坏吞吐保证。

最近邻轨迹不包含外观特征、速度预测或遮挡恢复。
两个目标交叉、合并再分开，或单帧位移很大时，可能换号、重新确认或漏框。
红色判定也不等于红绿灯识别；红墙、衣服等均可能成为候选。
本版没有将运动前景改为多个目标，也没有 CNN、台阶或障碍物识别。

## 帧身份、DDR 与跨时钟

`target_detect_switch_96.v` 为颜色与运动结果保留各自的原帧号和帧首检测模式。
颜色结果可在下一次 SOF 后才完成；结果选择按其携带的帧号查上下文，
而不是读取当前帧模式。两种完成脉冲同时出现时，先发布颜色结果、暂存运动结果；
接口约定每个检测器每帧最多发布一个结果，不支持任意密集的连续双源完成流。

`target_frame_bridge.v` 在帧首记录 10 位 `frame_id`、16 位递增 `nonce`、
显示配置、运动位和 2 位颜色模式。在真实 DDR 写槽分配时绑定这些身份，
结果只有帧号、nonce、运动位和颜色模式都匹配才可写入对应槽。
四个上下文槽使用完整帧号校验，过期、已被替换的上下文被丢弃；
不能仅凭帧号低两位或回绕后的同一帧号接受旧结果。
完整 720p 帧要求 172,800 个 128 位写字，短帧不能使结果成为可显示有效记录。

DDR 实际选择读槽时冻结结果快照，HDMI 在帧首提交整组框、形状、保持标记及显示配置，
同一显示帧内不改框。冻结点后才到达的结果不补画到当前扫描帧；
下次再次读取仍匹配的完整原帧时才可使用。
槽复用、写入回滚、重复显示、早到/迟到结果均有专门回归。
显示偏移随原帧配置绑定：模式 02/06/07 向右下各 3 像素，
模式 04/08/10/11 各 1 像素，模式 12 各 3 像素，其他为 0，
补偿后限幅到 1279×719。

元数据采用保持载荷的请求/确认传输，发送方在 ACK 前不覆盖正在传输的总线。
两份顶层 SDC 都约束帧上下文 CSI→DDR 为 **20 ns**、
检测结果 CSI→DDR 为 **20 ns**、读槽快照 DDR→HDMI 为 **13 ns**；
异步请求/确认只在第一级同步器入口排除异步时序。
显示配置系统时钟→CSI 邮箱另保留 **13 ns** 约束。
本版最终构建已核对三组目标元数据约束全部有效：
上下文 6,216 条、结果 2,312 条、显示快照 257 条；显示配置为 4 条。
没有无效约束或无路径约束。
