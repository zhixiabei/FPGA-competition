# 五类水果 CNN 重新训练结果

基于 `fruits5_selected_20261031` 的全部 998 张筛选图片，从随机初始化开始训练。

网络与原水果模型相同：`fruit_scharr_texture_rgb128_v1`，128×128 RGB 输入，七层 Conv/BN/ReLU，通道 12/12/24/32/48/64/96，4×4 平均池化，384→5 全连接，推理参数 110,393。

形状使用固定正负 Scharr 梯度及原有形状辅助监督；纹理保留固定正负 Laplacian 特征及 4×4 单元 LBP 直方图辅助监督；颜色保留完整 RGB 输入、相同归一化和颜色增强。训练使用形状头 64 维、纹理头 160 维，推理权重按原规则移除辅助头。

| 类别 | 训练 | 验证 | 测试 |
|---|---:|---:|---:|

按重复组划分，各集合之间没有重复组、文件哈希或模型输入哈希重叠。142 张手机图片来自同批水果的连续拍摄，全部归入训练集，避免同一拍摄对象泄漏到验证或测试集。验证和测试结果因此反映留出的网络图片，不能作为独立手机拍摄准确率。

## 训练与结果

使用 RTX 4060 Laptop GPU / PyTorch 2.6.0+cu124。完整沿用原训练配置：AdamW、学习率 0.002、weight decay 0.002、batch 48、seed 20261024、160 轮上限、至少 60 轮、30 轮早停耐心值、AMP、每轮重复 2 次、形状/纹理损失权重各 0.1、苹果/橘子配对权重 0.15、异常样本权重 0.05、硬件缩放输入概率 0.5、拒识阈值 0.65；数据增强、类别加权、标签平滑、选模规则与原训练脚本相同。

实际完成 **105 轮**，最佳权重来自 **第 75 轮**。仅使用验证集选模与校准温度，冻结权重后评估测试集。

| 测试视图 | 准确率 | 宏平均召回率 |
|---|---:|---:|
| 原始图像预处理 | 86.67% | 84.84% |
| 模拟硬件缩放 | 88.00% | 88.79% |
| 灰度输入 | 79.33% | 76.81% |

## 文件

- `training/model.pt`：已经完成训练和校准的最佳推理权重。
- `training/last.pt`：最后一轮训练状态，包含优化器、随机状态和辅助头，可断点续训。
- `train.py`：使用相同配置重新训练；后续新训练自动使用新的 runs 子目录。
- `predict.py`：默认加载本文件夹的新权重，支持图片或摄像头。
- `source/`：本次训练使用的原实现快照。
- `data/`：独立复制的 train/validation/test 图片、训练清单和分组记录。
- `training/evaluation.json`、`training/test_predictions.csv`：详细测试结果。
- `verification_report.json`：与原模型的结构、固定滤波器、预处理和训练参数一致性检查。
- `training_curves.png`、`test_confusion_matrix.png`：训练曲线与测试混淆矩阵。
- `logs/`：训练控制台日志。

## 使用

在项目根目录使用原来的 CUDA 解释器：

```powershell
.\.conda\fruitcuda\python.exe fruitcnn128_retrained_20261031\predict.py --image "图片路径.jpg"
.\.conda\fruitcuda\python.exe fruitcnn128_retrained_20261031\predict.py --camera 0
.\.conda\fruitcuda\python.exe fruitcnn128_retrained_20261031\train.py
```

原脚本恢复训练会遵循断点内保存的训练配置；已完成的断点会直接报告完成，若要重新训练请直接运行 `train.py`。

本次产物是浮点 CNN 权重及训练记录。尚未对新权重执行 FPGA 定点量化、综合或上板测试。原模型文件保留。
